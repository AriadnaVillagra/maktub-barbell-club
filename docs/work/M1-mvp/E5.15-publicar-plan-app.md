# E5.15 — App: botón Publicar en el editor de plan

## Cambio

Agregar al editor el estado del plan (borrador o publicado) y el botón "Publicar".

## Dónde cae

- `apps/frontend/lib/features/plan/`: `plan_editor_page.dart`, `presentation/providers.dart`, `domain/plan_repository.dart`, `data/http_plan_repository.dart`.
- `apps/frontend/lib/features/plan/presentation/plans_page.dart`: estado en la lista.

## Debe ser cierto después

- "Publicar" siempre se ve, y se habilita solo si el plan está guardado, `validatePlan` no da ningún problema y hay algo sin publicar.
- El editor indica si el plan es un borrador, si está publicado o si está publicado con cambios sin publicar.
- Publicar actualiza el estado sin perder el borrador. Un error del servidor se muestra, con la lista de problemas si es un 422.
- No se puede publicar dos veces a la vez.
- La lista de planes muestra si cada uno es borrador o publicado.
- Tests de widgets con repositorio falso; `flutter test` y `flutter analyze` pasan en `apps/frontend`.

## Restricciones

- Solo tokens y componentes de `maktub_ui` (CLAUDE.md, "maktub_ui").
