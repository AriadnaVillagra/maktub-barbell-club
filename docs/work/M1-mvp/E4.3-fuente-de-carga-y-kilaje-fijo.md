# E4.3 — Fuente de carga y kilaje fijo

## Cambio

Una serie toma su kilo del RM del atleta (con factor y %) si el ejercicio tiene referencia y la serie tiene %; si no, toma el kilaje fijo que el coach cargó para ese atleta y ejercicio.

## Dónde cae

- `packages/maktub_core/lib/src/reglas/`: archivo nuevo o junto a `porcentajes.dart`. Usa el objetivo de E4.1.
- El kilaje fijo por atleta y ejercicio es el modelo de E3 (tarea 3.1).
- Referencia: `reference/Index.html`, `pesoDeSerie`, que decide entre RM y kilaje fijo. La fuente del kilaje fijo es `pesosAccesorios_` en `reference/Api.gs`.
- `reference/DISENO.md`, tabla "Bloque / Origen" y "Equipo".

## Debe ser cierto después

- Ejercicio con referencia y serie con % (y el RM del atleta cargado): kilo = objetivo de E4.1.
- Serie con % y RM faltante: sin peso propuesto (vacío, no cero).
- Ejercicio sin referencia: kilo = kilaje fijo del atleta para ese ejercicio. Sin kilaje cargado, sin peso propuesto.
- Ejercicio con referencia pero serie sin %: cae al kilaje fijo, como en la referencia.
- Hay tests para cada uno de los cuatro caminos.

## Restricciones

- Código nuevo en inglés (`CLAUDE.md`, "new code is written in English").
- Regla pura en `maktub_core`, con tests (`CLAUDE.md`, "Architecture › maktub_core").
- Si el kilaje fijo se redondea al cargable más cercano, es una decisión pendiente (la referencia no lo redondea). Esta issue no la resuelve; el kilaje fijo sale tal como está cargado mientras tanto.

## Decisiones cerradas

- Un ejercicio sin referencia carga por kilaje fijo, y esa es la única distinción; no hay campo "es accesorio" (`reference/DISENO.md`, "Bloque / Origen").
- El kilaje fijo es por atleta (M1 §3, "kilaje fijo para accesorios").

## Bloqueos externos

- Modelo de kilaje fijo de E3 (tarea 3.1).
