# E2.1 — Modelos de ejercicio, categoría, grupo muscular y patrón

## Cambio

Agregar en `maktub_core` los modelos de ámbito, ejercicio, categoría, grupo muscular y patrón con los campos de F2 §4, su JSON y sus validaciones puras.

## Dónde cae

- `packages/maktub_core/lib/src/modelos/`: junto a `base.dart` (`DelClub`, `Auditoria`), `cable.dart` (enums con nombre de cable) y `json.dart`. Seguir el patrón de `temporizador.dart`.
- `packages/maktub_core/lib/src/reglas/`: validaciones puras nuevas (referencia propia, ciclos, nombres únicos, profundidad de grupos).
- Exportar desde `packages/maktub_core/lib/maktub_core.dart`.

## Debe ser cierto después

- Ejercicio y categoría, con ámbito `base` o `club`, viajan ida y vuelta por JSON con los campos de F2 §4: categorías, métricas con objetivo por defecto, patrón, músculos con peso (`principal` 100 %, `secundario` 50 %), referencia de carga, sugerencias, notas y estado (`activo` o `archivado`).
- Grupo muscular y patrón, con ámbito, viajan ida y vuelta por JSON. Un grupo del club puede tener padre; un grupo base no. La profundidad máxima es dos niveles (base → hijo del club).
- Los músculos y el patrón de un ejercicio apuntan a grupos y patrones visibles para su club.
- Las métricas son las de F2 §4 (carga por % de RM, carga fija, peso corporal ± lastre, repeticiones, tiempo, distancia, ritmo, zona cardíaca, calorías, intento).
- Una referencia `propia` sin carga × repeticiones entre las métricas se rechaza.
- Un ciclo de referencias (A → B → A) se rechaza. El RM efectivo de una cadena es el final de la cadena.
- Un ejercicio base solo puede referenciar a otro base. Uno del club puede referenciar a base o a del club.
- Los nombres son únicos dentro de un conjunto visible, comparados sin mayúsculas ni acentos.
- Hay tests unitarios por cada validación y del round trip JSON de cada modelo.

## Restricciones

- CLAUDE.md › maktub_core: todos los campos que define el diseño, aunque la interfaz no los use; todo documento lleva `clubId` (la base usa `plataforma`); enums con nombre de cable estable.
- CLAUDE.md › Idioma: el código nuevo va en inglés. Las claves JSON no están fijadas por las fuentes (ver informe).
- F2 §5: reglas de referencia, ciclos, nombres y profundidad de grupos. Son la fuente de las validaciones.

## Decisiones cerradas

- Base y del club comparten el mismo modelo, con `clubId` reservado `plataforma` (F2 §4).
- Grupos musculares y patrones base entran en M1 como datos; su interfaz queda fuera (design.md D10).
