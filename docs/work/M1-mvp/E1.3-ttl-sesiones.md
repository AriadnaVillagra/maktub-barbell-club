# E1.3 — Limpieza de sesiones vencidas con índice TTL

## Cambio

Agregar un índice TTL sobre el vencimiento de `login_sessions` para que Mongo borre sola cada sesión al vencer.

## Dónde cae

- `apps/backend/lib/infraestructura/mongo.dart`: `asegurarIndices` ya crea el índice por `userId` sobre `Colecciones.loginSessions`.
- `apps/backend/lib/features/auth/start_session/start_session_store.dart`: el campo de vencimiento con el que se inserta la sesión. Hay que usar ese mismo campo en el índice.

## Debe ser cierto después

- Tras `asegurarIndices`, `login_sessions` tiene un índice TTL sobre el campo de vencimiento, que borra al vencer.
- Correr `asegurarIndices` dos veces no falla ni duplica el índice.
- Contra Mongo local (`docker compose up -d`), una sesión con vencimiento pasado desaparece sola. Un test chequea la definición del índice.

## Restricciones

- F1 §5 › Identidad: las sesiones vencidas se borran solas, con índice TTL.
- CLAUDE.md › Backend: `asegurarIndices` vive en `lib/infraestructura/`, solo código cross-cutting.
- Código nuevo en inglés (CLAUDE.md, intro).
- Debe estar antes del merge de E1 (design.md §4.1, D2).

## Decisiones cerradas

- Limpieza por índice TTL, no por job (F1 §5).
