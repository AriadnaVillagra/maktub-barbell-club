# E0.1 — Cargar el origen de Pages en la API

## Cambio

Redesplegar la API en Cloud Run con `ORIGENES_PERMITIDOS=https://ariadnavillagra.github.io`, para que el navegador acepte las respuestas de la API a la PWA publicada.

## Dónde cae

- `scripts/desplegar-backend.sh`: ya toma `ORIGENES_PERMITIDOS` del entorno y lo pasa a `--set-env-vars`. Se usa tal cual, sin cambios.
- `apps/backend/lib/infraestructura/http.dart`: `origenesDesdeEntorno()` y `cors()` ya cubren el caso. Sin cambios de código.
- Servicio `maktub-api` en Cloud Run (`europe-north1`, proyecto `maktub-514012`).

Es una acción manual sobre infraestructura: no hay código que escribir si el despliegue sale bien.

## Debe ser cierto después

- `curl -i -H "Origin: https://ariadnavillagra.github.io" https://maktub-api-312703406459.europe-north1.run.app/health` responde con `Access-Control-Allow-Origin: https://ariadnavillagra.github.io`.
- Un `OPTIONS` con ese origen responde 204 con `Access-Control-Allow-Headers` que incluye `Authorization`.
- Un origen con ruta o barra final mal cargado no matchea: el valor cargado es solo el origen (design.md §3.6).
- `http://localhost:<puerto>` sigue respondiendo con CORS (la API lo permite siempre).
- La variable queda fijada en el servicio: `gcloud run services describe` la muestra.

## Restricciones

- CLAUDE.md › Commands (línea de producción): el despliegue se hace con `ORIGENES_PERMITIDOS=... scripts/desplegar-backend.sh`.
- `desplegar-backend.sh` reescribe `ORIGENES_PERMITIDOS` en cada deploy, con valor vacío si no se pasa. Cualquier despliegue futuro sin la variable borra el origen. Hay que pasarla siempre.
- CLAUDE.md › Hosting: la API es un contenedor plano; no sumar nada específico de Google en el backend.

## Decisiones cerradas

- El origen es `https://ariadnavillagra.github.io`, sin ruta (design.md §3.6).
- Se carga en `ORIGENES_PERMITIDOS` y no se cambia el código de CORS (E0, "Qué entrega").

## Bloqueos externos

- `gcloud auth login` hecho por el usuario (CLAUDE.md › Commands: el despliegue lo requiere).
