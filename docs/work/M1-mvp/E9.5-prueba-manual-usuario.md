# E9.5 — Prueba manual del usuario sobre la PWA de producción

## Cambio

El usuario hace su prueba manual sobre la PWA de producción, con las correcciones de E9.4 ya publicadas, y la acepta o anota lo que falta. Es una prueba manual.

## Dónde cae

- PWA de producción en `https://<usuario>.github.io`.
- Backend de producción en Cloud Run.

## Debe ser cierto después

- El usuario hizo la prueba sobre la PWA de producción.
- La aceptación queda registrada por el usuario.

## Restricciones

- Lo que el usuario encuentre se corrige dentro de E9. Si no es corrección, no entra.
- Las pruebas de E9.2 y E9.3 no se repiten salvo que el usuario lo pida.

## Bloqueos externos

- Disponibilidad del usuario.
