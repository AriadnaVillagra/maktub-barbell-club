# E2.9 — App: categorías, temporizadores y equipo

## Cambio

Agregar en la PWA las pantallas de categorías y temporizadores propios del club, y la de equipo con la vista previa de pesos cargables.

## Dónde cae

- `apps/frontend/lib/features/catalogo/{data,domain,presentation}`, junto a E2.8 (mismo feature, o un feature hermano si el tamaño lo pide; decidir al hacerlo).
- Cálculo de pesos cargables: `packages/maktub_core/lib/src/reglas/equipo.dart` (E2.2).
- Componentes: `packages/maktub_ui/lib/src/`.

## Debe ser cierto después

- El coach crea, edita y archiva categorías y temporizadores propios desde la app.
- Las categorías y temporizadores base se listan fijos, sin acciones de edición (F2 criterio 7).
- El coach edita barra y discos del equipo, y ve una vista previa de los pesos cargables con el equipo que está editando (F2 §6, "Equipo").
- Un atleta solo lee estas pantallas (F2 criterio 9).
- El coach completa estas tareas sin tocar la base (M1 criterio 2).
- Hay tests de repositorio falso y de pantalla para las tres pantallas.

## Restricciones

- CLAUDE.md › Frontend: clean architecture por feature.
- CLAUDE.md › maktub_ui: sin literales; componentes nuevos al paquete con galería.
- F2 §6 "Pantallas", "Categorías, grupos y patrones": esta épica cubre categorías, temporizadores y equipo. Grupos y patrones quedan fuera (E2 "Excluye").

## Decisiones cerradas

- Las categorías y los temporizadores base no se editan desde el club (F2 §5).
