# E6.2 — Backend: lectura de grupos y alta del grupo de Andi y Ari

## Cambio

Agregá el slice de lectura de grupos en `apps/backend/lib/features/grupos/`: listar los grupos
del club. Tiene su `<slice>_store.dart` con la interfaz y la implementación Mongo. La colección
de grupos se declara en `Colecciones`, con índice por `clubId`.

No hay endpoint de creación: el grupo lo crea el script de alta (D14). Extendé el script de alta
de E1.9 para que cree el grupo de Andi y Ari, con sus dos atletas como miembros. La carga es
idempotente.

## Dónde cae

- `apps/backend/lib/features/grupos/` (slice de lectura y store).
- `routes/` solo despacha por método HTTP.
- Script de alta: el mismo de E1.9 (su ubicación la fija ese issue).
- Tests con stores falsos en `apps/backend/test/features/grupos/`, y un test del script.

## Debe ser cierto después

- Todas las consultas filtran por `clubId`. El test de aislamiento de E1.11 corre sobre el
  endpoint nuevo.
- Listar exige `Accion.verCatalogoYPlanes`: lo ven el coach y el atleta del club.
- Correr el script de alta dos veces no duplica el grupo.
- Los miembros del grupo son atletas del club (E3.4).
- `dart test` y `dart analyze` limpios en `apps/backend`.
