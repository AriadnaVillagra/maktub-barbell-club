# E9.4 — Corregir los problemas de la prueba en el gimnasio

## Cambio

Corregir cada problema de la lista de E9.3. Solo correcciones: si un problema pide funcionalidad nueva, no entra acá.

## Dónde cae

- Depende de cada problema. No se puede derivar hasta tener la lista de E9.3.

## Debe ser cierto después

- Cada problema de la lista está corregido.
- Las correcciones pasan los tests de los miembros que tocan.
- Las correcciones que tocan código llegan a la PWA y al backend de producción.

- Código nuevo en inglés (CLAUDE.md). El código existente sigue en español.
- Los colores, tamaños y estilos de las pantallas salen de `maktub_ui` (CLAUDE.md).
- Las reglas de carga en `maktub_core` se corrigen ahí, con tests.
